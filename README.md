# Lending 101

## Overview

This repository contains my solution for the `lending-101` workshop.

It includes the main Aave integration contract and the script used to execute the solution flow on Sepolia.

## Main Files

- `src/solutions/LendingExerciseSolution.sol`
- `script/SolveLending101.s.sol`

## Notes

The additional interface files and constants included in this repository are direct dependencies of the submitted solution.

The published `ex9` flash-loan step is not executable as written because of an issue in the workshop evaluator.

## Result

This solution was used to complete `ex1` to `ex8` of the `lending-101` workshop on Sepolia.
